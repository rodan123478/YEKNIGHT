**¿Qué es Pygame?**
Pygame es una biblioteca de Python utilizada para crear videojuegos en 2D. Permite crear ventanas, personajes, movimientos, sonidos, imágenes y detectar
colisiones.

**Relación de Pygame con los temas de clase**
**Pygame permite aplicar diferentes conceptos de programación:**
**Variables:** almacenan datos como velocidad y posición.
**Ciclos:** permiten mantener el juego funcionando.
**Condicionales:** permiten tomar decisiones dentro del juego.
**Listas:** organizan información como enemigos y objetos.
**Funciones:** dividen el código en partes reutilizables.
**Eventos:** detectan acciones del jugador, como presionar teclas.

**Uso de la librería Pygame**
Pygame permite utilizar muchas o pocas de sus herramientas dependiendo de las necesidades del proyecto. Por ejemplo, podemos utilizar únicamente ventanas y
movimientos para un juego sencillo, o agregar imágenes y colisiones para un juego más avanzado.
Esto permite desarrollar videojuegos de diferentes niveles de complejidad.
